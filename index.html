01

Internet = una red de redes

No es una sola máquina. Es una gigantesca colección de redes y dispositivos conectados entre sí.

🏠 CASA

Tu teléfono, computador y otros dispositivos pueden formar una red local.

🏫 COLEGIO

Un colegio puede tener muchos dispositivos conectados a su propia red.

🌎 INTERNET

Las redes se conectan entre sí para permitir la comunicación.

ANALOGÍA: imagina muchas carreteras conectadas. Cada red es como una zona de carreteras y los routers ayudan a encontrar caminos.

03

IP: la dirección del dispositivo

Para comunicarse, los dispositivos utilizan direcciones de red. Una dirección IP ayuda a identificar un destino.

142.250.72.14
Dirección IP de ejemplo

📬 Piensa en una dirección

Así como una carta necesita una dirección para llegar a un lugar, los datos necesitan información de destino para viajar por una red.
